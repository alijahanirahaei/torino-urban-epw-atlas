Repository guide

Use, data, and repository structure

Authors: Ali JahaniRahaei and Giacomo Chiesa.

Published atlas · Source repository

The atlas is a static website. Hosted users need no installation: query a coordinate, inspect the assignment and quality fields, then download the candidate EPW or exact UWG JSON configuration.

Run locally

python3 -m http.server 8000

Open http://localhost:8000. Serving over HTTP is required because browsers can block local GeoJSON requests from a file:// page.

Command-line lookup

python3 scripts/lookup.py 45.0757395 7.6785426

The command uses only the Python standard library and returns the same grid, morphology, category, EPW, configuration, and warning information as JSON.

Repository automation

GitHub Actions validates pushes and pull requests. The Pages workflow repeats validation before deploying the static atlas from main, and maintainers can also start it manually. The workflows use scoped GitHub permissions and store no deployment credentials.

Scientific scope

The four files are candidate UWG outputs. Displayed UHI is modeled relative to AvMY Caselle, not measured local UHI. Edge and outlier warnings should be retained in downstream interpretation.
