# Supplementary material v1.1.0

This package accompanies atlas v0.3.0 and retains the v0.2.0 weather library.
It clarifies the weighted scale-variance decomposition, C6 applicability
safeguards, 2022 year selection and representative-count criterion. Document
tables and prose use readable numerical precision, and Figures S3-S6 have
larger labels. Exact source tables and configurations are unchanged.

Downloads:

- `torino_uwg_supplement_v1.1.0.zip`: Sections S1-S7 in Word, PDF and Markdown,
  Tables S1-S13, Figures S1-S6, additional diagnostic tables, exact configurations,
  the 105-job heat-sensitivity manifest and portable runner, licences and hashes.
- `supplementary_material.docx`: clean editable document.
- `supplementary_material.pdf`: fixed-layout reading copy.
- `supplement_checksums.sha256`: integrity hashes for the three downloads.

Raw weather inputs and generated simulation EPWs are not embedded in this
supplement. Obtain forcing from the documented companion dataset and library
EPWs from the atlas. No new simulation, classifier refit or empirical validation
is introduced. Version 1.0.0 remains available as a historical release.
