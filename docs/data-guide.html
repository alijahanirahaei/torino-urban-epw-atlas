Data guide

Formats and assignment fields

The canonical GeoPackage uses EPSG:3003 and contains the 12,997 assignment polygons, 19 medoids, and exact city boundary. Zipped shapefiles use the same metric CRS. The GeoJSON and browser lookup use WGS84.

Key fields

  • cluster_k4_provisional, cluster_k7_provisional, and cluster_k8_provisional: raw morphology assignments.
  • epw_category: reduced A-D weather category derived from k=7 medoid outputs.
  • edge_support: the 500 m support crosses the municipal GIS boundary.
  • qa_score and qa_reasons: explicit data-quality conditions.
  • distance_to_medoid_k7: robust-scaled morphology distance.

Weather and configuration downloads

Each A-D category links to one annual candidate EPW and the exact UWG JSON configuration used to generate it. These are modeled research outputs, not measured local weather records. Displayed UHI is UWG-simulated relative to AvMY Caselle and may differ from observations.
